# 日常会話スピーキング練習アプリ 画面構成

## 1. 画面設計の方針

最初のMVPでは、アプリを開いてから最初の会話を始めるまでの時間をできるだけ短くする。

そのため、ホームで迷わせすぎず、「テーマを選ぶ」「会話する」「短く振り返る」「気になった表現を残す」という最小導線を中心に設計する。

同時に、将来テーマ追加や難易度分岐をしやすいよう、会話の軸を「場面」「トーン」「目的」で整理できる構造にしておく。

## 2. 全体マップ

### MVPで必須の画面

1. ウェルカム / オンボーディング
2. ホーム
3. 会話テーマ一覧
4. 会話テーマ詳細
5. 会話画面
6. 会話後フィードバック
7. 復習一覧
8. 学習設定

### 将来追加しやすい画面

1. 会話キャラクター選択
2. 難易度別練習一覧
3. 1日の学習履歴
4. 苦手表現ダッシュボード
5. 発音特化トレーニング

## 3. 各画面の役割

### 1. ウェルカム / オンボーディング

目的:
このアプリが「英語で返す練習」に特化していることを短く伝え、最初の会話テーマへ進ませる。

主な要素:
- 会話練習アプリであることの説明
- 1回3分から5分で試せる案内
- 音声入力が使えることの紹介
- 最初のおすすめテーマへの導線

### 2. ホーム

目的:
その日どのテーマで話すかを、できるだけ迷わず決められるようにする。

主な要素:
- 今日のおすすめテーマ
- 直近で残した苦手表現
- すぐ始めるボタン
- テーマ一覧への導線
- 継続状況の軽い表示

将来拡張:
- 会話時間の目安表示
- 気分別おすすめ
- 朝用 / 夜用ショートカット

### 3. 会話テーマ一覧

目的:
場面や気分に応じて、話したいテーマを選べるようにする。

主な要素:
- テーマカード
- 難易度
- 想定会話時間
- タグ
  - 自己紹介
  - 雑談
  - カフェ
  - 旅行
  - 初対面

### 4. 会話テーマ詳細

目的:
そのテーマでどんな会話になるかを見せて、安心して開始できるようにする。

主な要素:
- テーマ名
- 想定シーン
- よく出る話題
- 会話の雰囲気
  - casual
  - friendly
  - simple
- 開始ボタン

### 5. 会話画面

目的:
AIとの日常会話を、止まりにくく、恥ずかしさが出にくい形で続けられるようにする。

主な要素:
- AIの現在の発話
- 会話履歴
- 音声入力ボタン
- テキスト入力欄
- 詰まった時のヒントボタン
- 会話終了ボタン

UX上の重要点:
- 毎ターンで添削しすぎない
- 今どちらが話しているかを明確にする
- 会話を止めずに続けやすい操作にする

### 6. 会話後フィードバック

目的:
会話を終えたあとに、学習価値を感じられる最小限の振り返りを返す。

主な要素:
- 今日できていた点
- より自然な言い換え
- 次回すぐ使える一文
- 苦手表現を保存するボタン
- 同じテーマをもう一度話す導線
- 別テーマに進む導線

### 7. 復習一覧

目的:
あとで言いづらかった表現だけを軽く見直せるようにする。

主な要素:
- 保存した表現一覧
- テーマ別フィルタ
- 次にそのまま使いたい一文
- 再挑戦ボタン

### 8. 学習設定

目的:
会話体験をその人向けに少しずつ寄せられる余地を持たせる。

主な要素:
- 英語レベル
- 会話で伸ばしたいこと
  - 話し始め
  - 会話継続
  - 自然な言い換え
- 1回の会話時間目安
- フィードバックの細かさ

## 4. 基本導線

### 初回利用フロー

1. ウェルカムを見る
2. おすすめテーマを選ぶ
3. 会話を1本やってみる
4. フィードバックを見る
5. 気になった表現を復習に残す

### 日常利用フロー

1. ホームを開く
2. 今日のおすすめか前回の続きから始める
3. 3分から5分会話する
4. フィードバックを見る
5. 必要なら復習一覧へ送る

### 集中練習フロー

1. テーマ一覧を開く
2. 同じ系統のテーマを連続で選ぶ
3. 会話を2本から3本続ける
4. 苦手表現だけ復習一覧で見返す

## 5. ナビゲーション案

スマホ前提なら、下部または上部ナビゲーションは4つが扱いやすい。

- ホーム
- テーマ
- 復習
- 設定

会話画面は独立タブではなく、ホームやテーマ一覧から入る形にする。

## 6. MVP時点で実装優先度が高い画面

最優先:
- ホーム
- 会話テーマ一覧
- 会話テーマ詳細
- 会話画面
- 会話後フィードバック
- 復習一覧

後回しでもよい:
- 細かい学習設定
- 高度な進捗分析
- 会話キャラクター分岐

## 7. 将来の拡張につながる設計ポイント

- テーマを「場面」「トーン」「目的」でタグ管理できるようにする
- AI返答と学習者返答を会話ログとして残しやすくする
- フィードバックを「自然さ」「言いやすさ」「継続力」で分類できるようにする
- 復習表現を単独カードとして再利用できるようにする

## 8. 次工程への引き継ぎメモ

次のMVP仕様書では、各画面について以下を定義すると実装へ進みやすい。

- 画面ごとの目的
- 入力項目
- 出力項目
- 完了条件
- MVPに入れるもの
- 後回しにするもの
- 必要データ
