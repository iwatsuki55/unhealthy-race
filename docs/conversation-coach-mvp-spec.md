# 日常会話スピーキング練習アプリ MVP仕様書

## 1. 目的

本MVPは、英語学習者がAIと短い日常会話を続けながら、英語を返す瞬発力と会話継続力を伸ばすためのスピーキング練習アプリを作ることを目的とする。

重点は以下の3点に置く。

- AIと短い会話を自然に続けられること
- 音声で返す練習を気軽に繰り返せること
- 会話後に短い振り返りと復習導線を得られること

## 2. MVPの前提

- 対象端末はスマホを優先する
- 初期利用者はまず自分自身1人を想定する
- ログインなしでそのまま使える構成にする
- 会話テーマは日常会話の基本場面に絞る
- リアルタイム性より、会話が止まりにくいことを優先する

## 3. MVPで提供する機能

1. ウェルカム表示
2. 会話テーマ選択
3. テーマ詳細表示
4. AIとの会話セッション
5. 音声入力
6. テキスト入力
7. 会話後フィードバック
8. 苦手表現の簡易保存
9. 復習一覧表示
10. 簡易学習設定

## 4. 想定ユーザーストーリー

### 初回ユーザー

- ユーザーはアプリを開く
- このアプリが日常会話練習用であることを知る
- おすすめテーマを1つ選ぶ
- AIと3分程度会話する
- 会話後のフィードバックを見る
- 気になった表現を復習に残す

### 継続ユーザー

- ユーザーはホームから今日のおすすめを見る
- その日の気分に合うテーマを選ぶ
- 会話を1本完了する
- 言いづらかった表現だけ復習一覧で見返す

## 5. 画面別仕様

### 5-1. ウェルカム / オンボーディング

目的:
アプリの価値を短く伝え、最初の会話テーマ選択へつなげる。

入力:
- なし

出力:
- アプリ説明
- 主機能紹介
- 最初のおすすめテーマへの導線

完了条件:
- ユーザーがホームまたはテーマ一覧へ進む

MVP範囲:
- 1ページまたは2ページ程度の簡易説明

後回し:
- パーソナライズ分岐
- チュートリアル動画

### 5-2. ホーム

目的:
今日どの会話をするかを最短で選べるようにする。

入力:
- おすすめテーマ選択
- テーマ一覧へ進む操作

出力:
- 今日のおすすめテーマ
- 直近の復習候補
- すぐ始めるボタン
- 継続状況の簡易表示

完了条件:
- ユーザーが任意の会話導線に進める

MVP範囲:
- おすすめ1件
- 復習候補3件
- 累計会話数などの簡易サマリー

後回し:
- 詳細履歴
- 気分別おすすめ
- 時間帯別提案

### 5-3. 会話テーマ一覧

目的:
日常会話の場面から話したいテーマを選べるようにする。

入力:
- テーマ選択
- タグ選択

出力:
- テーマカード一覧
- 想定会話時間
- 難易度
- タグ

完了条件:
- テーマ詳細へ進める

MVP範囲:
- 3から5テーマ
- シンプルな一覧表示

後回し:
- 検索
- 難易度フィルタ
- キャラクターフィルタ

### 5-4. 会話テーマ詳細

目的:
そのテーマでどんな会話になるかを理解し、安心して開始できるようにする。

入力:
- 会話開始

出力:
- テーマ名
- 想定シーン
- 会話の雰囲気
- よく出る話題
- 会話時間目安

完了条件:
- 会話画面を開始できる

MVP範囲:
- シーン説明
- 開始ボタン

後回し:
- キャラクター変更
- 難易度切替

### 5-5. 会話画面

目的:
AIと英語で短い会話を続ける練習をする。

入力:
- 音声入力開始
- 音声入力停止
- テキスト入力
- メッセージ送信
- ヒント表示
- 会話終了

出力:
- AIの現在発話
- 会話履歴
- 音声認識結果
- 送信済みの自分の返答
- 必要時の短いヒント

完了条件:
- 最低3往復以上のやり取りを行い、終了できる

MVP範囲:
- 1テーマあたり3から5ターンの会話
- AI応答
- 音声またはテキストで返答

後回し:
- 完全リアルタイム音声会話
- 割り込み会話
- 感情表現の細かい演出

### 5-6. 会話後フィードバック

目的:
会話終了後に、短く振り返って次の一歩を持ち帰れるようにする。

入力:
- 復習追加
- 同じテーマでもう一度
- 別テーマへ進む

出力:
- 今日できていた点
- 不自然だった返し
- 言いやすい代替表現
- 次回すぐ使いたい一文

完了条件:
- ユーザーが次の行動を選べる

MVP範囲:
- 短い文章によるフィードバック
- 復習候補の提示

後回し:
- 詳細スキル分析
- ターンごとの長い添削

### 5-7. 復習一覧

目的:
言いづらかった表現だけを軽く見直して再挑戦しやすくする。

入力:
- テーマフィルタ
- 再挑戦開始

出力:
- 苦手表現一覧
- 理由
- 次に使いたい一文
- 再挑戦ボタン

完了条件:
- 任意の復習項目から再練習を開始できる

MVP範囲:
- 自動登録された苦手表現の一覧表示

後回し:
- 間隔反復ロジック
- 優先度自動調整

### 5-8. 学習設定

目的:
会話体験を自分向けに少し調整できるようにする。

入力:
- 英語レベル
- 伸ばしたい点
- 会話時間目安
- フィードバック粒度

出力:
- 設定値表示
- 次回会話への反映

完了条件:
- 最低1つの設定変更が保持される

MVP範囲:
- 表示とローカル保存中心

後回し:
- 詳細なレベル診断
- 自動最適化

## 6. 会話ロジック仕様

### 6-1. AIの役割

- 英会話講師ではなく、自然な会話相手兼やさしいコーチとして振る舞う
- 毎ターン添削で会話を止めない
- 会話が詰まりそうな時だけ短いヒントを返せる

### 6-2. 会話ターン設計

- AIが最初の一言を出す
- 学習者が返す
- AIがその返答を受けて自然に続ける
- 3から5ターンで1セッションに区切る

### 6-3. フィードバック粒度

- 会話中は最小限
- 会話終了後にまとめて返す
- 指摘は多くても3点程度に絞る

## 8. 技術実装メモ

- 既存 repo の音声入力ロジックを再利用できる
- AI評価 API と AI応答 API の土台を流用できる
- まずは `/conversation-coach` 配下に独立追加する
- 保存は最初はローカル保存中心でよい
- あとから Supabase 保存へ拡張できる構造にする

## 9. MVPで後回しにするもの

- ログイン
- ソーシャル共有

- 長期学習グラフ
- 完全リアルタイム音声会話
- 多人数会話

## 10. 完了条件

このMVPは、以下を満たせば成立とみなす。

- テーマを選んでAIとの会話を始められる
- 音声またはテキストで返答できる
- 会話が3往復以上続く
- 会話後に短いフィードバックが返る
- 気になった表現を復習一覧に送れる
