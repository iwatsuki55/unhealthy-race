# Health OS v0.1.0

Health OS v0.1.0 is the first local-first MVP of a personal digital health platform.

This release focuses on manual daily health management across Today, Running, Strength, Routes,
Goals, and Journal. It intentionally excludes AI, wearable integrations, weather, notifications,
cloud deployment infrastructure, and new health modules.

## Highlights

- Today Home as the daily command center
- Running Log with routes, heart rate, cadence, calories, weather context fields, shoes, notes, and screenshots
- Strength Training Log with workout type, equipment type, exercises, and sets
- Route Management with distance, estimated time, elevation, Google Maps URL, favorite, and active state
- Goal Management for running, strength, weight, body fat, pace, race, custom health, and custom goals
- Journal for daily notes, mood, fatigue, recovery, work stress, alcohol, sauna, and tags
- Local Prisma SQLite persistence
- Seed data for local development
- GitHub Issue Forms, Pull Request template, label taxonomy, and milestone plan

## Release Readiness

- CRUD workflows are available for Running, Strength, Routes, Goals, and Journal.
- Today aggregates module read models through application-level query services.
- Destructive actions require confirmation.
- Routes with historical runs are deactivated rather than destructively deleted.
- App-level loading, error, and not-found states are present.
- Forms are responsive and include cancel actions and pending submit states.
- Seed command is development-only and refuses to run in production.

## Known Limitations

- Settings is still a placeholder.
- There is no authentication or multi-user UI.
- Goal progress is deterministic and simple.
- Custom goals do not invent percentages.
- Race time and pace goals use manual numeric values without specialized goal editors.
- Labels and milestones are defined in YAML but still need GitHub-side sync if they have not been created in the repository UI.
- No AI Coach, Apple Health, Garmin, Strava, Google Calendar, weather, notifications, advanced charts, or cloud deployment infrastructure.
