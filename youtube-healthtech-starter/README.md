# YouTube Healthtech Starter

医療DX・ヘルステック系の YouTube 運用を半自動で回すための最小スターターです。

## 目的

- 企画は人が決める
- 台本、素材生成、動画書き出し、アップロード下書きは自動化する
- 公開前に必ず人が確認する

## 前提

- 医療情報は高リスクなので、診断・治療の断定表現は避ける
- 必要に応じて医療監修フローを入れる
- YouTube へのアップロードはまず `private` で行う

## フォルダ

- `config/`: チャンネル設定、プロンプト、運用ルール
- `data/`: 企画、下調べ、台本、メタデータ
- `assets/`: 画像、音声、サムネ、BGM
- `output/`: 確認用動画と最終版
- `logs/`: 実行ログ
- `src/`: 自動化スクリプトの置き場
- `tmp/`: 一時ファイル

## 最初の使い方

1. `config/channel.json` をチャンネルに合わせて編集する
2. `notion/NOTION_DB_TEMPLATE.md` を見ながら Notion DB を作る
3. `notion/notion_import_template.csv` を必要なら初期インポートに使う
4. `data/ideas/` に企画を置く
5. 台本生成から動画化の処理を `src/` に実装する

## 推奨ルール

- 企画は狭いテーマで統一する
- 医療助言に見える表現は公開前に見直す
- 根拠ソースを `data/research/` に残す
- サムネとタイトルで誤認を誘わない
